# 七項系統設計檢查

七項是設計檢查表，不是七層流水線。

| 項目 | 應回答的問題 |
|---|---|
| Brain | 誰理解目標、調度並重新規劃？ |
| Agents | 哪個角色對哪項產出負責？ |
| Tools | 工具是否已連接且獲授權？ |
| Memory | 是否區分任務狀態與可信知識？ |
| Feedback | 錯誤如何發現、修正與重驗？ |
| Human | 哪些決定要交由人作出？ |
| Evidence | 每項結果能否回溯來源與驗收依據？ |

全程另衡量 Task Economics：品質、成本、時間、風險。評估應對照相同任務範圍與驗收標準，不預設 AI 一定比較便宜。
