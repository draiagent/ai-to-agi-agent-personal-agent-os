## GitHub 網頁上傳

1. 建立名稱為 `ai-to-agi-agent-personal-agent-os` 的 repository。
2. 選定可見性。不要另外勾選產生 README 或授權，避免與本套件衝突。
3. 解壓 ZIP，開啟同名資料夾，將其中內容上傳到 repository 根目錄；不要直接上傳 ZIP 作為原始碼。
4. 確認首頁 README 顯示、7 張圖卡及文件連結可開啟。
5. 授權與檢查完成後，以 `v0.1.0` 建立 Release，使用 [Release Notes](../releases/v0.1.0.md)。
